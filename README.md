# Dice3D - 3D Physics Dice App

3D 物理骰子应用 - Android 平台，基于 OpenGL ES + Libbulletjme 物理引擎

## 功能特性

- 🎲 **多种骰子类型**: D4, D6, D8, D10, D12, D20, D100
- ⚡ **真实物理模拟**: 使用 Libbulletjme (Bullet Physics) 引擎
- 🎨 **3D渲染**: OpenGL ES 2.0 + 自定义着色器
- 📳 **触觉反馈**: 碰撞时震动反馈
- 🎯 **陀螺仪投掷**: 摇晃设备投掷骰子
- 🌙 **深色模式**: 支持跟随系统设置

## 技术栈

- **物理引擎**: Libbulletjme (Bullet Physics)
- **UI框架**: Jetpack Compose
- **数据库**: Room
- **架构**: MVVM
- **最小SDK**: 24 (Android 7.0)
- **目标SDK**: 35 (Android 15)
